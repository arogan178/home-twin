Trace your home once. Plan its lighting with your AI agent, to the millimetre.

Home Twin keeps your floor plan as an IFC building model on your own computer. You place lights on a plan or in 3D. Your agent places them through MCP. Both of you edit the same model, and every change passes the same checks before it is saved.

The same room, as your agent reads it

Home Twin runs an MCP server beside the plan. Your agent asks for the room and gets the lights you see, in millimetres, with their IFC identities. When it moves one, the change goes through the same checks and the same verified save as yours.

Point at a light on the drawing to find it here.

From a scanned drawing to an electrician's schedule

  1. Trace the plan over a scan of the drawing, and check the scale against two printed dimensions.
  2. Build the model. The trace compiles into an IFC file that is reopened and verified before it replaces anything.
  3. Place the lights: spotlights, pendants, rope lights and switches, by hand or through your agent.
  4. Check the layout for spacing, wall clearance, cabinetry, shadow gaps and shadows cast by joinery.
  5. Export the schedule as CSV, JSON and SVG, with every light's tag and coordinates for the installer.

What it won't claim

It does not simulate lux.
Light estimates are a labelled lumen and beam-cone approximation. Every number and every picture of a light pool says which method made it.
It never guesses where you live.
Sun paths need the site and true north stated in the model. Without them, the sun panel says the site is unknown.
It is not BIM authoring software.
Straight walls, flat ceilings and rectangular openings are traced in the browser. Curved walls and sloped ceilings still belong in Bonsai.

Run it on your own computer

Home Twin is a local web app. The server listens only on your machine, and your model stays a file you own.

git clone https://github.com/arogan178/home-twin
cd home-twin
npm --prefix ui ci && npm --prefix ui run build
uv sync --extra dev
uv run python scripts/create_sample_ifc.py --force
uv run home-twin-ui --model model/house.ifc

Needs Python 3.11 or newer, Node.js 22.12 or newer, and uv. Point your agent at uv run home-twin-mcp --model model/house.ifc.
